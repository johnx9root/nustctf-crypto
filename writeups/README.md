# Coast & Campus: Blind Crypto Writeups

**Tagline:** Blind solves from Windhoek labs to the Skeleton Coast  
**Author:** John_x9  
**Event brand:** Coast & Campus

These are player-style **blind** writeups: you start from the attachment files only, work the puzzle step by step, then land the flag. Each challenge also has a clearly labeled **After the event** section on vulnerable construction and how to fix it. That part is for learning after you have solved; it is not required for a blind path.

Scripts live in [`solves/`](solves/). Point them at the downloaded challenge files (path as argv, or place the file beside the script).
